# Changelog

## 1.0.5 - 2026-06-05

- Added an admin-only "Remove this cover" action on the scanned result screen.
- Added a serial-number confirmation dialog before deleting a cylinder cover.
- Added client support for deleting cylinder covers through the cylinder cover hook.
- Updated the scanned result success modal to handle delete outcomes separately from update outcomes.
- Prevented deleted cylinder covers from being written into history after confirmation.
- Replaced the old single save button with a dedicated scanned-result action layout that supports primary and remove actions.
- Added English and Japanese translations for the new remove and delete success flows.
